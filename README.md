# Flower Classification

This project classifies Iris flowers using machine learning models in a Jupyter notebook.

## Project Files

- `app.ipynb` - Main notebook for data loading, exploration, visualization, model training, evaluation, and prediction.

## What The Notebook Does

- Loads the built-in Iris dataset from scikit-learn.
- Explores the dataset with pandas.
- Visualizes feature relationships with seaborn and matplotlib.
- Trains Logistic Regression and Decision Tree models.
- Compares model accuracy.
- Shows confusion matrices.
- Accepts user input for flower measurements and predicts the species.

## Requirements

Install the required Python packages:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

## How To Run

Start Jupyter Notebook:

```bash
jupyter notebook
```

Then open `app.ipynb` and run the cells from top to bottom.

## Input Features

The prediction cell asks for:

- Sepal length
- Sepal width
- Petal length
- Petal width

The model predicts one of these flower species:

- Setosa
- Versicolor
- Virginica
